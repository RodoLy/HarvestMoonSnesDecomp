Harvest Moon (SNES) - native build, v1.0.0 beta
===============================================

The game runs on its code rewritten in C. No ROM and nothing taken from
it is included: you need your own legal copy of Harvest Moon (USA). The
first time, the program asks for it (.sfc or .smc), checks it and
remembers it.

WINDOWS 10/11
    Open HarvestMoonNative.exe. If Windows says "Windows protected your
    PC" (the program is not signed with a paid certificate): More info >
    Run anyway.

MAC (Apple Silicon or Intel, macOS 11+)
    Double-click "Harvest Moon.command". If macOS says it is from an
    unidentified developer: right-click it > Open > Open (or, in
    Terminal: xattr -dr com.apple.quarantine on this folder).

ANDROID (phones, tablets, the AYN Thor)
    Open the .apk on the device to install it. If Android says it cannot
    install unknown apps from this source: Settings > allow it, then
    Install (and Install anyway if Play Protect asks). Choose your ROM with
    Android's file picker. On the AYN Thor launch the app on the top
    screen: the pause menu stays on the lower one while you play.

LINUX
    ./HarvestMoonNative  (or ./HarvestMoonNative /path/to/your/rom.sfc)

Everything starts OFF: the game is the console's. Turn on what you like
in the launcher (Esc): Improvements (widescreen, the Harvest Moon 64-style
pause menu, the crop bag, your wife's help, fast text, longer days...),
Cheats and Options.

MODS: put each mod (a folder with .ips or .bps patches and a mod.ini) in
the mods folder, then turn it on in the launcher's Mods page. How to make
one: mods/MODS.md.

Keys: arrows, X = A, Z = B, S = X, A = Y, C = L, V = R, Enter = Start,
Right Shift = Select. Esc launcher, M pause menu, Tab fast forward,
F11 full screen, F1-F10 load a state, Shift+F1-F10 save one.
A gamepad works too. Everything can be changed in Controls.

The source, and scripts to build it yourself:
https://github.com/RodoLy/HarvestMoonSnesDecomp
This is a beta: please report problems in the repository's Issues.

El juego corre sobre su codigo reescrito en C. No incluye la ROM ni nada
sacado de ella: necesitas tu propia copia legal de Harvest Moon (USA). La
primera vez el programa te la pide (.sfc o .smc), la revisa y la recuerda.

WINDOWS 10/11
    Abre HarvestMoonNative.exe. Si Windows dice "Windows protegio tu PC"
    (el programa no esta firmado con un certificado de pago): Mas
    informacion > Ejecutar de todas formas.

MAC (Apple Silicon o Intel, macOS 11+)
    Doble clic en "Harvest Moon.command". Si macOS dice que es de un
    desarrollador no identificado: clic derecho > Abrir > Abrir (o, en
    Terminal: xattr -dr com.apple.quarantine sobre esta carpeta).

ANDROID (telefonos, tablets, la AYN Thor)
    Abre el .apk en el equipo para instalarlo. Si Android dice que no
    puede instalar apps desconocidas de esta fuente: Ajustes > permitirlo,
    luego Instalar (e Instalar de todas formas si Play Protect pregunta). Elige tu ROM con el
    selector de archivos de Android. En la AYN Thor abre la app en la
    pantalla de arriba: el menu de pausa se queda en la de abajo.

LINUX
    ./HarvestMoonNative  (o ./HarvestMoonNative /ruta/a/tu/rom.sfc)

Todo viene APAGADO: el juego es el de la consola. Activa lo que quieras
en el launcher (Esc): Mejoras (pantalla ancha, menu de pausa estilo
Harvest Moon 64, mochila de cosechas, la ayuda de tu esposa, texto
rapido, dias mas largos...), Trucos y Opciones. El idioma se cambia en
Options > Language.

MODS: pon cada mod (una carpeta con parches .ips o .bps y un mod.ini) en
la carpeta mods y activalo en la pagina Mods del launcher. Como hacer
uno: mods/MODS.es.md.

Shift derecho = Select. Esc launcher, M menu de pausa, Tab avance rapido,
F11 pantalla completa, F1-F10 cargar un estado, Shift+F1-F10 guardarlo.
